## Overview
<a id="overview"></a>

NetGhost is a powerful tool designed for users who frequently connect to multiple WLANs (wireless local area networks). It simplifies the process of managing IP configurations, allowing users to define unique IP parameters for each network they connect to. By detecting the SSID (Service Set Identifier) of the connected WLAN, NetGhost automatically applies the user's pre-established IP configurations. Unlike many alternatives, NetGhost focuses solely on this task, ensuring that users can efficiently handle their network settings without complications.
